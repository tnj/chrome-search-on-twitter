# Privacy Policy for Search URL on X Chrome Extension

## Introduction
This Privacy Policy explains what information the "Search URL on X" Chrome extension collects and how it is used.

## Data Collection
**The "Search URL on X" extension does not collect, store, or transmit any personal data or browsing information.**

## How the Extension Works
The extension performs the following operations:
1. Accesses the URL of the current active tab when the extension button is clicked
2. Checks if there is a canonical URL defined on the current page
3. Creates a new tab with an X search URL that includes the current page URL as a search parameter

## Data Usage
- The extension does not store any user data locally or in the cloud
- The extension does not use cookies or any tracking mechanisms
- The extension does not share any information with third parties
- The extension does not use analytics or telemetry services

## Permissions Required
The extension requires only the following permissions:
- "tabs": To access the URL of the current tab and create a new tab for the X search

## Changes to This Privacy Policy
If we decide to change our privacy policy, we will update this document and notify users as required by the Chrome Web Store policies.

## Contact
If you have any questions about this Privacy Policy, please open an issue on [the extension's repository](https://github.com/tnj/chrome-search-on-twitter) or contact the developer.
